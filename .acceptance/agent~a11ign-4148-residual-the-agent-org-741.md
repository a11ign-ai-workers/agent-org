The gh ledger names who spent the pool, per hour (a11ign/a11ign#4148 residual, a11ign/agent-org#741). Two defects, one deliverable: the ledger answers "which caller, per hour".

**1. The caller arrives with its script's name.** `host/gh` cut the calling process's command line at 160 characters (`cut -c1-160`) AFTER the `--import file:///.../crash-exit.ts` preload a unit starts under, so the name of the script, which comes after the preload, was cut off. The preload is now taken out (`sed`, the same pattern `gh-ledger.ts` `PRELOAD` takes out when it reads) BEFORE the cut. A line already in a ledger is read as it was.

**2. The hourly rollup carries the caller.** `rollup_dropped` keys on hour, account, resource AND the caller's script and writes it as a seventh field. `script()` in the wrapper's awk is `callerScript` in awk; the test feeds both the same fifteen callers (a preload in both spellings, a double space, a `node -e` program that names its script, a session's shell, a first word that is no script, empty) and asserts the same name for each. A six-field line is read as it was, kept six fields by the next trim, and named `(caller not recorded)` by `perHourCallers`: its calls are never given a caller. `gh-ledger.ts <ledger> --per-hour --top <n>` prints each hour's top `<n>` callers by floor points under the hour's line; `--per-hour` alone prints what it always did.

**The tests** (`src/gh-ledger.test.ts`, section 4, three; each fails on `host/gh` as it stands at `origin/main`, measured): (a) a unit run under a real `--import` preload through the wrapper, whose preload alone puts the script's name past the 160th character (asserted first, with the same unit WITHOUT its preload fitting, so the preload is what lost the name), arrives as `work-gate.ts`; (b) fifteen callers and a trim that drops every line leave a rollup whose seventh fields are the names `callerScript` gives, and `--per-hour --top 2` names the two top callers of the hour; (c) a six-field rollup line beside a seven-field one survives a trim as six fields, merges only with its own kind, and reads `(caller not recorded)`.

Mutation, three, each red in the tests named and each restore byte-identical (copy in the scratchpad, `diff`): the preload strip removed from the writer (a only); the awk never strips a preload (b only); the seventh field never written (b and c, and `gh-ledger-per-hour.test.ts`'s "one row per hour" case, which the mutation breaks by merging rows its key now splits). `host/gh` as at `origin/main` fails all three.
